## 二、第一阶段：筑基、排障与抓取通路打通（第 1 - 30 天）

### 1. 核心战略定位
**「消除硬伤，让搜索引擎真正看见软游部落」**。  
此阶段不盲目追求新内容的大跃进，重点是将 Nginx 网关阻断、Sitemap 重复、占位符存根教程以及断链等阻碍爬虫正常工作的缺陷彻底清零。

### 2. 关键业务动作
1. **解除 Nginx 正则限制，释放全站 SSR 潜力**：
   - 移除正则末尾的 `$`，放行所有软件、工具、游戏、教程二级页面至 Fastify SSR 服务；
   - 在爬虫白名单中加入 `GPTBot`、`ClaudeBot`、`PerplexityBot`、`DeepSeekBot` 等主流 AI 爬虫。
2. **Sitemap 规范化治理**：
   - 清理 `sitemap-software.xml` 中冗余的 `/tool/` 别名条目，保证提交的均为规范 Canonical URL；
   - 消除 `sitemap-essentials.xml` 与 `sitemap-topics.xml` 的重复收录项。
3. **内容硬伤歼灭战**：
   - 彻底重写 Windows 11 安装指南（1400+字）与 7-Zip AES-256 加密实战（1000+字）；
   - 扩充 10 篇薄弱教程至 800+ 字，全面杜绝 Thin Content 降权风险；
   - 补齐 3 款系统镜像资源的官方正规获取途径说明。
4. **上线 AEO 基础设施**：
   - 部署根目录 `/llms.txt` 与 `/llms-full.txt`；
   - 在 SSR 模板中注入 `FAQPage` 与 `HowTo` 结构化数据，提供开箱即用的富媒体卡片。
5. **站长平台主动握手**：
   - 向 Google Search Console、Bing Webmaster、百度搜索资源平台全量提交 Sitemap 并进行重点 URL 批量推送；
   - 启用 IndexNow 协议实现毫秒级变更通知。

## 三、第二阶段：长尾词簇扩充与主题柱体系建设（第 31 - 60 天）

### 1. 核心战略定位
**「深耕长尾痛点，打造主题支柱（Topic Clusters），实现流量破局」**。  
当全站 77 项初始资产被搜索引擎稳定收录后，通过「核心软件 + 实操教程 + 痛点排障」的三角矩阵，建立高转化长尾词的网络壁垒。

### 2. 关键业务动作
1. **草稿池高价值软件增量核验与发布（从 50 款扩充至 70 款）**：
   - 重点审核并发布已在教程中被频繁引用的开源神器：
     - 开发与运维：`Git`, `Wireshark`, `PuTTY`, `DBeaver`；
     - 生产力与创作：`OBS Studio`, `LibreOffice`, `Obsidian`；
     - 系统精简与备份：`Dism++`, `Ventoy` 高级插件版；
   - 严格落实 P9.0.2 官方证据链核验标准，录入官方数字证书与 SHA256。
2. **教程矩阵长尾扩展（从 27 篇扩充至 45 篇）**：
   - 围绕用户痛点最密集的五大核心支柱展开系统化撰写：
     - **支柱一：系统重装与激活排障**（UEFI 双系统引导修复、Win10/11 数字权利迁移原理、BitLocker 恢复密钥找回）；
     - **支柱二：电脑卡顿与流氓软件强力卸载**（顽固弹窗进程定位、恶意浏览器主页劫持清除、开机自启项深度清理）；
     - **支柱三：私有数据安全与加密备份**（BitLocker + VeraCrypt 双重容器加密、NAS 局域网高速同步配置）；
     - **支柱四：开源替代商业软件全攻略**（LibreOffice 代替 MS Office 格式兼容技巧、GIMP 代替 PS、Kdenlive 剪辑实操）；
     - **支柱五：网络排障与抓包实战**（Wireshark 排查局域网丢包、DNS 污染诊断与 DoH 安全解析配置）。
3. **强化「装机必备（Essentials）」主题聚合页权重**：
   - 将「程序员装机必备」、「设计剪辑装机必备」、「办公文员轻量装机必备」等核心专题页进行结构化升级，作为 PageRank 的重要蓄水池向各底层软件页分发权重。
4. **内部链接网状互联**：
   - 软件页自动展示该软件的 2-3 篇关联教程；
   - 教程页自动嵌入配套软件的版本、官方下载入口与哈希校验框；
   - 页面间跳出率（Bounce Rate）降低 20%，用户平均停留时长提升至 2 分钟以上。

## 四、第三阶段：品牌实体权威确立、AEO 深度引用与谨慎商业化（第 61 - 90 天）

### 1. 核心战略定位
**「确立官方核验品牌权威，成为 AI 搜索首选信源，构建可持续健康生态」**。  
软游部落在传统搜索中形成稳定的品牌检索词，在生成式 AI 中沉淀为高质量知识实体，探索完全合规、不损体验的良性商业化路径。

### 2. 关键业务动作
1. **品牌知识图谱实体化（Knowledge Graph Consolidation）**：
   - 完善全站 Schema.org 中的 `Organization` 实体信息，关联官方 GitHub 组织、技术博客、开发者社交主页（`sameAs` 属性）；
   - 强化 E-E-A-T 体系：为技术团队核心成员建立专门的「审核工程师档案页」，列明专业背景与安全核验声明；
   - 争取在百度百科、互动百科或知乎建立「软游部落」品牌权威词条，提升搜索引擎实体置信度。
2. **AI 搜索引用的全场景验证与语义优化**：
   - 针对 DeepSeek、豆包、千问、Kimi、Perplexity 进行周期性 Prompt 探针测试：
     - 测试词一：「Windows 干净无捆绑软件下载网站推荐」；
     - 测试词二：「7-Zip 官方正版下载地址与防踩坑」；
     - 测试词三：「如何纯净安装 Win11 跳过联网登录」；
   - 依据 AI 检索器的偏好，持续增强文章前言的「原子事实提炼」与「结论先行摘要（Executive Summary）」。
3. **高质量开发者社区与开源生态反向链接（Backlinks）建设**：
   - **绝不购买低质垃圾外链或 PBN 链接网**；
   - 通过高质量技术输出建立正规自然外链：
     - 将经过严格核验的软件收录与版本追踪工具开源到 GitHub（`zhjlin11/softbuluo`），吸引开源社区与开发者自然引用；
     - 在 V2EX、掘金、知乎等技术社区针对「如何安全下载正版软件」、「如何排查流氓捆绑」等话题输出高质量科普长文，自然带出软游部落的官方证据链页面；
     - 与开源软件作者（如 OpenRA 社区、TrafficMonitor 作者等）取得良性互动，争取被官方推荐或链接。
4. **探索谨慎、透明、合规的商业化闭环（Commercialization Exploration）**：
   - **坚决拒绝**：任何形式的捆绑安装包、高速下载器广告、欺诈性大下载按钮、流氓弹窗联盟广告；
   - **正规尝试**：
     - 优质正版软件合法分销（如数码荔枝、软购商城官方合作 CPS，标注「正版授权购买通道」，与免费开源通道并列展示）；
     - 优质云服务商官方开发者扶持计划（如腾讯云/阿里云开发者主机扶持链接，放置于底部合规赞助栏）；
     - 读者自愿赞赏（爱发电/赞助者鸣谢墙）。

### 日常运营监控与周会机制
1. **每周一晨会（SEO 数据巡检）**：
   - 提取 Google Search Console 与百度站长平台的抓取频次与 4xx/5xx 报错；
   - 检查是否有新产生的死链或异常重定向；

   - 严格执行「撰写 -> 官方环境实操上机验证 -> 截图与参数核对 -> 双人代码级复核 -> 批准发布」的闭环 SOP；
   - 发布后自动同步到 Sitemap，并通过 API 推送给各大搜索引擎。

## 六、合规红线与安全边界声明

在 90 天路线图的推进全过程中，全体技术与运营团队必须坚守以下铁律：
1. **坚守七大核心导航**：严禁随意调整顶部导航栏，始终聚焦于软件、工具、游戏、装机、教程与更新的核心用户心智；
2. **安全无捆绑的绝对承诺**：所有收录软件必须提供官方原版通道或经严格哈希比对的原厂文件，严禁任何形式的再打包、广告插件注入；
3. **白帽 SEO 铁律**：严禁关键词堆砌（Keyword Stuffing）、隐藏文字、虚假重定向（Cloaking）或购买机器外链；
4. **生产发布授权制**：严禁未经审核与确认自动向生产数据库写入未核验数据，所有生产变更均需具备快速回滚机制（Rollback Ready）。
