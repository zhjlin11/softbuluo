## 一、改版前状况与基线回顾

在本次 P8.7.8 之前，软游部落已依次完成了系统工具、游戏中心、装机必备、最新更新等频道的独立 UI 3.0 门户化升级。而在软件教程栏目存在以下基线问题：
1. **列表页缺乏门户化架构**：原页面仅有简单的单一列表与客户端本地粗粒度过滤，无法与服务端分页结合。
2. **缺乏热门排障快捷解决入口**：缺少普通用户最常遇到的“电脑蓝屏”、“Win11原版装机”、“跳过TPM限制”、“自启流氓项清理”等高频问题直达路径。
3. **详情页硬编码假步骤**：旧版详情页固定硬编码了 3 个无意义的假小节标题，下方简单通过 `whitespace-pre-line` 堆叠正文，Markdown 结构（标题、代码块、引用、图片、表格）严重破损。
4. **正文可读性与实操能力缺失**：没有动态提取章节目录（TOC）、代码块无法复制、图片无法放大、无高风险系统操作提示、无操作前准备清单。
5. **SEO 与 SSR 缺失**：`/tutorials` 频道首页未在服务端注册专属 SSR 路由，无法向搜索引擎蜘蛛输出完备的 HTML5 语义。

## 三、UI 3.0 门户化核心设计变化

### 3.1 顶部 Hero 架构（65% 焦点实操 + 35% 热门排障）
- **左侧 65% 焦点实操卡片**：
  - 聚焦重磅实操文章（如原版纯净装机、Rufus 启动盘制作），展示分类、难度、耗时、平台、标签及直达按钮。
- **右侧 35% 热门排障解决中心**：
  - 提炼 6 大真实硬件排障与故障高频场景（蓝屏卡死检测、避开流氓 PE 装机、跳过 TPM、开机自启清理、网络抓包分析、自建私有远控）。
  - 每个问题均附带场景标签与一键直达链接，绝不放置无内容的假入口。

### 3.2 多维检索与分类筛选栏
- **分类标签 Tabs**：实时同步真实文章收录计数 Pill。
- **关键词搜索**：支持在标题、摘要、标签及关联软件名中全局模糊匹配。
- **难度等级筛选**：入门友好（BEGINNER）、进阶实操（INTERMEDIATE）、专业技术（ADVANCED）。
- **操作系统筛选**：Windows 11、Windows 10 / 通用、跨平台 (Win/Mac/Linux)。
- **多维排序规则**：最新发布优先（latest）、阅读热度优先（views）、最近技术复核（updated）。
- **URL 状态同步**：所有筛选条件与 `useSearchParams` 实时联动，支持浏览器刷新与历史回退。

### 3.3 精选教程图文卡片
- 呈现分类胶囊、难度等级、耗时预测、阅读量统计、支持平台。
- 若文章关联软件，展示轻量级软件图标与版本芯片。
- 采用微阴影悬浮位移动效，在移动端与桌面端保持一致视觉质感。

## 四、核心升级：沉浸式教程阅读器（`/tutorials/:slug`）

### 4.1 头部技术元数据与导读
- 标明“软游部落技术专家组”编写。
- 严格区分“发布日期”与“最后人工复核时间”（杜绝使用虚假时间戳冒充复核）。
- 呈现操作系统要求、预计耗时、阅读次数与实操复核声明徽标。
- 显著的“核心导读与目标”摘要引用框。

### 4.2 操作前准备清单（`TutorialPreflight`）
- 依据不同教程动态配置 1~3 项操作前置核验点（例如“是否已备份重要数据”、“是否具备管理员权限”、“是否准备好 8GB U 盘”）。
- 用户可实时勾选辅助自检，标注清晰说明：“勾选仅供读者阅读核对，不代表已对设备自动检测”。

### 4.3 高风险操作安全警示横幅（`TutorialRiskBanner`）
- 针对涉及**磁盘格式化、系统引导篡改、注册表批量清理**的高风险操作（如 Rufus、Ventoy、Autoruns），展示显目的琥珀色告警横幅。
- 强制提醒用户备份关键数据、核实驱动器号、创建系统还原点，坚决不把不可逆操作包装成“一键安全搞定”。

### 4.4 Markdown 渲染器与代码块一键复制（`TutorialMarkdownRenderer`）
- **代码块优化**：支持 `powershell`、`cmd`、`bash`、`python` 语法高亮与深色终端风格。
- **一键复制能力**：右上角提供“复制”按钮，点击后呈现“已复制”绿色 Check 状态反馈（2秒后自动恢复）。
- **横向防溢出**：代码块与长表格具备自身 `overflow-x-auto` 容器，绝不破坏页面全局布局。

### 4.5 真实 H2/H3 目录导航与阅读进度（`TutorialTOC`）
- 自动从正文 Markdown 提取所有二级（`##`）与三级（`###`）标题。
- 自动生成唯一的 `heading-n` 锚点 ID。
- **桌面端**：右侧吸顶卡片，基于 Scrollspy 自动高亮当前阅读章节，点击平滑滚动。
- **移动端**：自适应折叠抽屉条，可展开/收起章节目录，点击后自动收起并平滑定位。
- **顶部进度条**：随页面滚动实时呈现 0% ~ 100% 细长渐变阅读进度。

### 4.6 图片全屏放大预览 Lightbox（`ImageLightbox`）
- 正文图片支持点击全屏遮罩预览。
- 附带图片说明文本（Caption）。
- 支持点击遮罩关闭或按下键盘 `ESC` 退出。

### 4.7 P8.8 正版软件下载联动与同类推荐（`RelatedSoftwareCard`）
- 右侧边栏直接展示教程涉及的正版软件信息（图标、开发者、最新版本号）。
- 接入 P8.8 官方直链体系，注明原厂防篡改比对提示，一键直达 `/software/:slug` 详情页。
- 底部提供同类推荐教程与上一篇/下一篇教程导航。
