## 五、应用安全与权限边界审计

1. **身份鉴权物理隔离**：后台管理员使用独立会话上下文（`req.session.user`），前台会员使用 `req.session.member`。普通会员越权访问后台管理路由直接触发 `403 FORBIDDEN` 强阻断。
2. **TokenVersion 原子失效**：支持密码修改后全局撤回旧会话，防御凭据劫持。
3. **SSRF 拦截保护**：外链健康探活模块强制校验目标 IP，严禁请求 127.0.0.1、内网网段与云元数据接口。
4. **敏感字段防护**：公开接口经 Prisma 字段投影（`select`），密码散列、用户邮箱与内部 Token 发生率为 0。
