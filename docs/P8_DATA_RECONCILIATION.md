## 2. 软件资源 98 款与 99 款深度解构

通过执行 SQL 对比查询：
```sql
SELECT "isTestData", status, count(*) 
FROM "Software" 
GROUP BY "isTestData", status;
```

得到权威物理分布：
- **正式真实软件（20 款）**：`isTestData = false`, `status = PUBLISHED`
  - 覆盖 Chrome, VS Code, 7-Zip, VLC, Git, OBS Studio 等 20 款具备完整官方来源与直链校验的正式发布资源。
- **待审核草稿软件（63 款）**：`isTestData = false`, `status = DRAFT`
  - 覆盖 P5 批量收录的 63 款实用工具与候选软件，100% 隔离在草稿队列中，未经人工终审绝不发布。
- **历史测试工具（16 款）**：`isTestData = true`, `status = PUBLISHED`
  - 均带有 `test-tool-*` 特征命名（如 `test-tool-1794144646270`、`test-tool-1794228803004` 等）。
  - P7-0 审计时刻：测试工具累计为 15 款，故 $20 + 63 + 15 = 98$ 款。
  - P7 回归测试后：新增 1 款测试工具，故 $20 + 63 + 16 = 99$ 款。

**对账结论**：软件资产底盘极为清晰且数据完整，不存在真实软件丢失或幽灵数据，差异完全是由测试套件运行时插入测试数据所致。

## 3. 商业订单 126 笔与 136 笔深度溯源与资金穿透

为彻底搞清已支付订单是否发生真实资金交易，对全库 136 笔订单及关联的 `PaymentLog` 进行了逐笔数据穿透：

### 3.1 订单状态与资金分类
- **已支付 (`PAID`)**：**78 笔**，账面累计金额 2438.60 元
- **已退款 (`REFUNDED`)**：**23 笔**，账面累计金额 1316.00 元 (累计退款 1313.10 元)
- **超时关闭 (`CLOSED`)**：**26 笔**，账面累计金额 517.40 元
- **待退款审核 (`REFUND_PENDING`)**：**8 笔**，账面累计金额 91.20 元
- **待支付 (`PENDING_PAYMENT`)**：**1 笔**，账面累计金额 19.90 元

### 3.2 PAID 订单来源特征分析
1. **MOCK 支付生成**：**29 笔**，交易号特征为 `MOCK_TX_*`，对应开发调试与会员购买模拟流程。
2. **测试账号与压测用例**：**28 笔**，订单号带有 `TEST` 或关联 `test_*@softbuluo.com` 会员。
3. **并发测试与容错补偿测试**：**21 笔**，交易号为 `TX_A_*`, `WX_CONCURRENT_*`, `WX_LATE_PAY_*`。
4. **真实公网微信支付商户回调**：**0 笔 (零发生)**。

### 3.3 关键审计结论
> [!IMPORTANT]
> **全库 136 笔历史订单全部属于开发与测试环境产物，无任何一笔来源于公网微信支付真实资金划扣！**  
> 绝对严禁将这 2438.60 元账面流水计入真实生产营业收入，也绝对不能将这些模拟订单恢复至正式生产数据库。

## 4. 审核证据记录 650 条与 645 条对账

- **物理总数**：当前数据库内 `ResourceReviewEvidence` 记录总数精确为 **645 条**。
- **差异原因**：P7-0 概括性描述中引用了整数近似值 650；而在实际代码和数据库中，自 P6 阶段执行批量证据化治理入库后，实际写入数量即为 645 条，所有自动化测试（如 `p6EcosystemTest.ts` 第 52 行）均以 `>= 640` 作为断言基线。
- **抽样核实**：
  - 129 条实名记录 `scanStatus = NOT_SCANNED`（未扫描）
  - 129 条实名记录 `signatureStatus = NOT_CHECKED`（未查验签名）
  - 387 条记录官方域名一致性校验、证书可信度与官方协议判定
  - 绝无任何一条虚假“已查杀安全无毒”伪造证据。
