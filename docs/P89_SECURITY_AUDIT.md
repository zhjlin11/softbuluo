# 软游部落 P8.9 全站应用安全、权限边界与网络架构审计报告

## 一、权限架构与会话隔离安全审计

软游部落（SoftTribe）后端采用 Fastify 框架，严格实现了 **后台管理员** 与 **前台普通会员** 的**物理级会话隔离**。

```
                     ┌───────────────────────────────────┐
                     │          客户端 HTTP 请求         │
                     └─────────────────┬─────────────────┘
                                       │
                     ┌─────────────────▼─────────────────┐
                     │   Fastify Session (@fastify/session)│
                     └─────────────────┬─────────────────┘
                                       │
                 ┌─────────────────────┴─────────────────────┐
                 │                                           │
  ┌──────────────▼──────────────┐             ┌──────────────▼──────────────┐
  │      req.session.user       │             │     req.session.member      │
  │     (后台管理员鉴权管道)    │             │    (前台会员业务鉴权管道)   │
  └──────────────┬──────────────┘             └──────────────┬──────────────┘
                 │                                           │
  ┌──────────────▼──────────────┐             ┌──────────────▼──────────────┐
  │   requireAuth 中间件拦截    │             │  requireMemberAuth 中间件   │
  │ • 检查 tokenVersion 版本    │             │ • 仅访问个人订单/收藏夹     │
  │ • 普通会员跨权直接 403 阻断 │             │ • 无法调用任何管理接口      │
  │ • 账号禁用原子注销          │             └─────────────────────────────┘
  └─────────────────────────────┘
```

### 1. 管理员鉴权机制与提权防护
- **中间件**：`server/src/middleware/auth.ts`
- **跨权拦截**：当检测到 `req.session.member` 试图访问 `/api/v1/admin/*` 管理端点时，系统直接响应 `403 FORBIDDEN (普通会员无权访问管理后台)`，彻底杜绝平行越权与垂直越权。
- **TokenVersion 原子失效**：管理员密码修改或安全登出时，系统递增数据库中的 `tokenVersion` 字段。所有已颁发的旧 Session 凭证在下次校验时自动触发 `401 SESSION_REVOKED` 并强制注销销毁，有效防御凭据窃取与重放攻击。

## 二、API 安全加固与防御机制

### 1. SSRF (服务端请求伪造) 拦截
- **防护位置**：下载直链探测与链接健康巡检服务 (`server/src/modules/linkHealth/`)
- **防御规则**：
  - 域名解析后立即校验目标 IP 是否位于私有保留网段：
    - `127.0.0.0/8` (Loopback 回环)
    - `10.0.0.0/8` (Class A 私网)
    - `172.16.0.0/12` (Class B 私网)
    - `192.168.0.0/16` (Class C 私网)
    - `169.254.169.254` (腾讯云/AWS 实例元数据服务)
  - 拦截直接返回 `SSRF_BLOCKED`，禁止服务端向本地端口及私网资产发起 HTTP/TCP 请求。

### 2. SQL 注入防御
- 全站数据操作 100% 依托 **Prisma ORM** 的类型化参数化查询（Parameterized Queries），无任何拼接未经清洗 SQL 字符串行为，杜绝经典 SQL 注入。

### 3. CORS 跨域安全
- **生产环境配置**：`origin: [config.clientUrl]`（仅允许 `https://softtribe.top`，严禁 `*` 通配符）。
- **凭证传递**：`credentials: true` 仅在受信任白名单域名生效。

### 4. 敏感信息防泄漏审计
- **公开接口扫描**：对 `/api/v1/channels/*`、`/api/v1/resources/*`、`/api/v1/tutorials/*` 进行了响应体字段审计：
  - 密码哈希 (`passwordHash` / `salt`)：**0 泄露**（Prisma 查询严格使用 `select` 排除私密字段）。
  - 用户真实邮箱：**0 泄露**。
  - 管理员 Token 与会话 Secret：**0 泄露**。

## 三、生产 Web 服务器与网络架构安全评估

### 1. Nginx 静态文件防直下策略
- 在 Nginx 配置中明确生效防护指令：
  ```nginx
  location ~* \.(?:exe|msi|zip|7z|dmg|pkg|deb|rpm|appimage)$ {
      return 404;
  }
  ```
- 前端静态 Web 根目录禁止直接暴露安装包下载，所有下载行为必须经由 Fastify `/api/v1/downloads/` 鉴权与流式中继，确保权限与防刷逻辑不被绕过。

### 2. 生产备用 8080 端口暴露风险分析 (ISS-06)
- **现状**：Nginx 在 `listen 8080` 开放了纯 HTTP 端口，允许直接通过 `http://134.175.230.107:8080` 访问。
- **风险分析**：
  1. 8080 端口未启用 SSL/TLS，传输过程明文，存在中间人劫持风险。
  2. 若用户在 8080 端口输入管理员凭据登录，可能导致 Session Cookie 在网络中明文传输。
- **治理与整改建议**：
  1. **短期（当前可用状态）**：严禁在 8080 端口执行任何管理员登录或敏感支付操作；仅用于纯静态只读验收。
  2. **中期（P9.0 运营前）**：配置安全组仅限特定运维 IP 访问 8080 端口，或将其从公网解绑仅监听 `127.0.0.1:8080`。
