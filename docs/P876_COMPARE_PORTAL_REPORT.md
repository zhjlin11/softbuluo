## 一、升级背景与核心改进

在历史版本中，`/compare` 页面仅为一个简易的评测长文卡片列表，存在以下核心短板：
1. **交互缺失**：用户无法自主挑选两款感兴趣的软件进行横向参数比较，只能被动阅读编辑预置的文章；
2. **数据未结构化**：软件规格、开源许可证、便携性、哈希防篡改等关键信息散落各处，缺乏一目了然的对比矩阵；
3. **选型决策路径断层**：用户面临"我该用哪款"的现实困境时缺乏明确的场景化、人群化决策建议；
4. **替代方案孤岛**：已审核的开源替代软件关系未在对比频道直接打通。

在 P8.7.6 中，我们完成了对 `/compare` 频道的彻底重构，将其打造成**交互式、场景化、可信的软件对比与选型门户**。

## 二、架构设计与核心功能模块

### 1. 顶部 65% / 35% 主题大图 Banner (`ComparePortalHero`)
- **左侧 65%**：
  - 醒目标题「软件横向对比与客观选型指南」，主打"真实环境实测、零商业充值软文"；
  - 核心数据看板：收录 **28 款**已发布可比软件、**2 篇**深度长文横评、**5 组**认证替代方案、**100% 真实测试环境**；
  - 快捷跳转按钮：直接平滑滚动至 A/B 对比矩阵或精选长文。
- **右侧 35%**：
  - 年度旗舰横评 VS Spotlight 焦点对决卡片（7-Zip vs PeaZip），展示双方软件图标、版本与许可证徽章；
  - 一键载入此组完整参数矩阵交互按钮。

### 2. 交互式双软件 A/B 参数对比矩阵 (`CompareSoftwareSelectorAndMatrix`)
- **双向下拉选择器**：
  - A 侧（对比基准）与 B 侧（对比目标）分别从 28 款已发布桌面软件中自由选择；
  - 严格边界校验：**禁止自我对比**（已选软件在另一侧自动置灰禁用，选择同名直接拦截并友好提示）；
  - 跨品类自适应：当所选软件跨品类时（如办公 vs 系统工具），顶部自适应展现跨品类选型提示，比对通用系统与安全指标。
- **快捷推荐对切换芯片（Quick Pairs）**：
  - 预设 6 组经典对决（7-Zip vs PeaZip、VS Code vs Sublime Text、CPU-Z vs HWiNFO64、LibreOffice vs Office 2024、Rufus vs DiskGenius、VLC vs OBS Studio）；
  - 单击任一芯片立即载入双软件选择框与矩阵。
- **操作工具栏**：
  - **互换左右软件 (Swap)**：一键翻转 A/B 位置并无缝反转矩阵列；
  - **清空对比 (Clear)**：重置选择并清除 URL 参数；
  - **分享此对比 (Share)**：复制包含当前对比参数的规范分享链接（`/compare?left=...&right=...`），支持剪贴板反馈与 URL 水合。
- **差异高亮与过滤切换器**：
  - 提供「仅显示差异项」开关，动态过滤显示存在差异的参数项，并在表头精确显示差异统计（如"共对比 25 项参数，存在 15 项差异"）；
  - 差异行提供醒目的视觉高亮徽标（差异/琥珀色标签）。
- **结构化 7 大维度参数矩阵**：
  1. **基本信息**：中文名、英文名、所属分类、最新稳定版本、安装包大小；
  2. **开源与商业许可**：开源协议/授权类型、免费/买断商业模式、商业使用合规性；
  3. **平台与兼容性**：支持操作系统架构、便携/免安装绿色单文件支持；
  4. **核心功能与规格**：核心架构与引擎、格式与功能丰富度、官方网站背书；
  5. **安装包与便携性**：分发打包形式、流氓捆绑/静默推广检测（软游部落编辑部真实环境实测全部通过）；
  6. **安全与哈希校验**：官方直链分发状态、SHA-256 安装包哈希完整性校验；
  7. **编辑部实测指标**：当存在精选评测时，动态注入实机冷启动耗时、内存占用开销等客观指标。
- **严格零虚假数据原则**：
  - 绝不伪造跑分、星级或假好评率；数据暂缺时均规范呈现「暂无可靠数据」中性占位符。

### 3. 场景化专业选型建议卡片 (`CompareDecisionGuide`)
针对真实软硬件使用需求，设立 4 大场景决策卡：
1. **日常办公与文字处理**（学生、文职人员、中小团队）：LibreOffice vs Office 2024；
2. **代码开发与文本处理**（全栈工程师、运维人员）：VS Code vs Sublime Text；
3. **电脑维修与硬件验机**（装机运维、售后工程师、二手验机）：CPU-Z vs HWiNFO64；
4. **压缩包解压与归档管理**（大文件归档、隐私文件加密）：7-Zip vs PeaZip。
每张卡片均提供细分人群、关键决策维度与一键载入对比。

### 4. 精选横向深度评测长文 (`CompareFeaturedArticles`)
- 收录 2 篇由软游部落技术团队基于物理测试机撰写的万字横评长文：
  - `7-Zip vs PeaZip：开源解压缩工具横向对比与选型指南`
  - `Visual Studio Code vs Sublime Text：深度横向对比与开发者选型指南`
- 展示对决图标、阅读次数、摘要、结论导读，支持"载入矩阵"与"阅读长文"双重动作。

### 5. 认证替代软件方案库 (`CompareAlternativeRecommendations`)
- 关联已审核通过的 5 组真实替代方案：
  - `DiskGenius` → `Rufus`（轻量启动引导盘制作替代）
  - `HWiNFO64` → `CPU-Z`（轻快验机场景免安装便携替代）
  - `Office 2024` → `LibreOffice`（高性价比自由开源办公替代）
  - `VS Code` → `Sublime Text`（超轻量文本秒开替代）
  - `7-Zip` → `PeaZip`（现代化美观界面与两步安全密钥替代）
- 展现双方许可证差异、替代理由，并支持直接载入矩阵。

### 6. 按分类探索竞品 (`CompareCategoryDiscovery`)
- 覆盖开发工具、办公软件、系统工具、影音播放等大类；
- 展示分类下代表软件、软件数量及建议同类对比对。

### 7. 对比软件目录索引 (`CompareCatalogSection`)
- 28 款已发布正版桌面软件全量展架；
- 支持关键词搜索（中文名、英文名、特性）、分类筛选及开源自由授权过滤；
- 卡片提供「+ 设为对比 A」与「+ 设为对比 B」快捷加入按钮。

## 三、SEO 与性能优化

1. **统一公开服务端渲染 (SSR)**：
   - 入口端点 `GET /compare` 与别名 `GET /seo/compare` 统一由 `SeoService.renderCompareChannelHtml()` 处理；
   - 包含正式语义化 `<h1>软件对比评测与专业选型中心</h1>`；
   - 规范规范标签 `<link rel="canonical" href="https://softtribe.top/compare">`；
   - 结构化数据：输出合规的 `CollectionPage` 与 `ItemList` schema JSON-LD。
2. **动态 Sitemap 索引一致性**：
   - `/sitemap.xml` 索引包含 `/sitemap-comparisons.xml`；
   - `/sitemap-comparisons.xml` 包含 `/compare` 频道 URL（daily 抓取频次，0.85 优先级）及已发布长文 URL。
3. **响应式与多视口 CLS 性能**：
   - 在 1440px、1280px、1024px、768px、430px、390px 全视口通过 Playwright 实测；
   - 矩阵表格采用 `min-w-0` 与局部 `overflow-x-auto` 容器，外层页面设置 `overflow-x-hidden`；
   - **全视口外层横向溢出率为 0**（所有视口 `scrollWidth === clientWidth`）。
