## 一、升级概述与设计原则

本次升级彻底革新了软游部落顶部导航第六个独立栏目——**社区交流 (Community)**。告别传统单薄死板的假论坛模板，构建了一个面向 Windows 系统维护、电脑疑难故障排障、正版软件使用心得与开发者技术答疑的 **UI 3.0 现代技术问答互助社区**。

### 1.1 核心设计与运营原则
1. **真实可信准则 (Zero Fake Data)**：绝对不伪造虚假机器人、虚假发帖或虚假在线人数。所有统计指标（主题数、回复数、已解决疑难数、解决率）均来自 PostgreSQL 真实全量数据库查询。
2. **问答闭环 (Accepted Answer Workflow)**：提问者或管理员可为有效排障方案点击“采纳最佳解答”，主题标记为“已解决”，并在详情页顶部以绿色高优先级卡片置顶呈现，让后来遇到同样问题的用户“一目了然获取正解”。
3. **高密度 70% / 30% 现代门户布局**：
   - 桌面端：左侧 70% 宽幅讨论流与多维过滤条 + 右侧 30% 独立固定侧边栏（发帖引导、实时统计指标、待解决求助列表、文明互助公约）。
   - 移动端：单列优雅流式堆叠，各断点零横向溢出。
4. **安全与治理防线**：全链路 Anti-XSS 实体清洗转义、5 分钟 3 篇频率限制防刷防护、违规内容多维举报机制与管理后台审核队列。
5. **官方认证开发者联动**：与 P6 开发者入驻体系深度贯通，已认证官方开发者参与讨论时自动点亮“官方认证开发者回复”专属蓝底徽章。

## 三、SEO 与服务端渲染 (SSR) 建设

1. **公开访问路由与 SSR HTML 生成**：
   - `GET /community`：服务端完整输出标准 HTML5 网页，预渲染最新 20 篇活跃讨论，首屏即被各大搜索引擎蜘蛛抓取。
   - `GET /community/thread/:id`：单篇讨论详情 SSR 输出，包含完整问题与各楼层回复。
2. **搜索引擎结构化数据 (JSON-LD)**：
   - 社区首页声明 Schema.org `CollectionPage` 与 `BreadcrumbList` 规范。
   - 讨论详情页声明标准 `QAPage` 语义模型，当帖子被题主采纳后，自动生成 `acceptedAnswer` 节点，包含解答内容、作者与提交时间，在 Google/百度等搜索引擎中可获得富文本问答摘要卡片展示。
3. **爬虫协议与站点地图**：
   - `robots.txt` 明确放行 `Allow: /community` 并声明 `Sitemap: https://softtribe.top/sitemap-community.xml`。
   - 动态站点地图 `GET /sitemap-community.xml` 实时提取所有公开发布的社区主题，输出规范 XML。
