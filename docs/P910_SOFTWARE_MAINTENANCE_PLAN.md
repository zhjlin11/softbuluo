## 一、已发布 50 款优质软件的常规巡检机制

已上线的 50 款软件是软游部落的立身之本，必须保证其“版本不脱节、链接不失效、版权不违规、说明不误导”。

### 1. 双周官方版本追踪机制（Version Tracking SOP）
- **工具支持**：后台 [AdminVersionMonitorPage.tsx](file:///e:/Code/新建文件夹/src/pages/admin/AdminVersionMonitorPage.tsx) 与 `VersionMonitorService`；
- **巡检频率**：每周三上午执行一次半自动版本巡检；
- **核验要求**：
  1. 系统比对官方原厂发布源（如 GitHub Releases、Sysinternals RSS、官网公告）；
  2. 当发现官方发布了新版本（如 Process Explorer 发布 v17.06 或 7-Zip 发布 24.09）：
     - 必须核实官方更新日志（Changelog）；
     - 必须提取官方最新直链或发布页，并计算/核对官方提供的 SHA-256 哈希值；
     - 严禁自动直接覆盖旧版本，必须在后台审核通过后，发版时间以官方实际 `releaseDate` 记录入库；
     - 旧版记录平滑存入版本演进历史，供需要兼容旧系统的用户回溯。

### 2. 每周下载链接健康巡检（Link Health SOP）
- **工具支持**：后台 [AdminLinkMonitorPage.tsx](file:///e:/Code/新建文件夹/src/pages/admin/AdminLinkMonitorPage.tsx) 与 `LinkMonitorService`；
- **巡检频率**：每周一凌晨 03:00 自动触发全站下载来源 HTTP HEAD/GET 探针巡检；
- **处置规则**：
  - **返回 200 / 302**：标记为 `HEALTHY`；
  - **返回 403 / 429**：可能存在防盗链或限流，人工接入真实浏览器验证是否可正常拉起下载；
  - **确认返回 404 / 502 / 域名解析失败**：
    - 立即将该来源标记为 `DOWN` 并暂时下线；
    - 若该软件具备备用官方发布页，系统自动平滑降级至官方下载落地页；
    - 绝不允许向普通用户展示无法下载的死链按钮。

## 二、剩余 42 款草稿软件的受控审核计划

目前生产与本地数据库中尚有 **42 款非测试草稿**（41 款高价值可用候选 + 1 款已安全归档的重复 `vs-code`）。
为杜绝“泥沙俱下、缺乏质检”的粗放扩张，严格执行**每周最多审核发布 5–10 款**的节奏。

### 1. 软件质量量化评分模型（0 - 100 分）
入选正式发布池的软件必须达到 **80 分以上**：

| 评估维度 | 权重 | 满分标准 | 扣分与一票否决规则 |
| :--- | :--- | :--- | :--- |
| **官方原厂真实性** | 30 分 | 拥有完全独立的官方顶级域名或知名开源组织认证托管页 | 无法提供官方域名或仅有第三方扒包站源，**直接一票否决（0分）** |
| **纯净度与安全性** | 25 分 | 安装包无诱导勾选、无静默常驻后台挖矿/全家桶插件、VirusTotal 0 误报 | 含有顽固恶意插件或诱导弹窗，**直接一票否决** |
| **实用价值与口碑** | 20 分 | 解决具体明确的 Windows 办公/装机/排障痛点，GitHub Star > 1000 或大众公认口碑神器 | 换皮玩具或功能严重缺失的残次软件，扣 10-20 分 |
| **资料与要素完整性** | 15 分 | 官方高清矢量图标、系统架构支持（x64/ARM64）、授权协议（GPL/MIT/商业免费）、清晰摘要 | 缺少架构说明扣 5 分，缺少开发团队扣 5 分 |
| **更新与维护活性** | 10 分 | 过去 18 个月内有活跃版本更新或官方确认已高度稳定无需频繁修改 | 开发者已彻底失联、官网域名被博彩劫持，**直接淘汰归档** |

## 三、退市、归档与软件下架合规政策（Decommissioning SOP）

为保持软游部落长期可信度，设立明确的“软件安全退市机制”：
1. **停止维护标记（Abandoned / Deprecated）**：
   - 官方已宣布不再维护（如经典但已过时的软件），页面必须显式打上标签：“⚠️ 该软件官方已停止更新，仅供旧系统兼容使用，推荐替代方案：XXX”。
2. **安全风险下架（Security Blacklist）**：
   - 一旦发现软件被供应链投毒、官方域名失联并转向赌博/恶意网址、或数字签名被吊销，**立即将其状态变更为 `ARCHIVED`**，前台页面与下载直链秒级切断，并在后台保留操作审计日志（`AuditLog`）。
