## 二、变更批次逐项明细与安全评估

### 【批次 1】PostgreSQL 自动备份增强与容量保护
- **变更目的**：为每日备份脚本增加「前置 2GB 磁盘水位熔断」与「SHA-256 完整性哈希校验」。
- **操作对象**：生产服务器 `/home/ubuntu/scripts/backup_db_daily.sh`
- **影响范围**：仅修改备份脚本，不影响线上运行中的 Docker 容器或 Fastify 进程。
- **是否停机**：**零停机**。
- **回滚方式**：从 `/home/ubuntu/scripts/backup_db_daily.sh.bak` 恢复。
- **预检状态**：本地脚本测试通过，隔离恢复演练 100% 成功。

### 【批次 2】8080 备用调试端口公网收敛（高风险安全操作）
- **变更目的**：消除绕过 HTTPS 的公网暴露面，将 8080 改为仅监听本地环回 `127.0.0.1:8080`，并从 UFW 移除公网放行。
- **操作对象**：
  1. `/etc/nginx/sites-available/softtribe.top.conf`（修改为 `listen 127.0.0.1:8080;`）
  2. `sudo ufw delete allow 8080/tcp`
- **影响范围**：公网通过 `http://134.175.230.107:8080` 访问将被拒绝；正常访客走 443 端口完全不受影响；服务器本地冒烟脚本完全不受影响。
- **是否停机**：**零停机**（Nginx 平滑 reload）。
- **回滚方式**：
  ```bash
  sudo sed -i 's/listen 127.0.0.1:8080;/listen 8080;/g' /etc/nginx/sites-available/softtribe.top.conf && sudo nginx -s reload
  sudo ufw allow 8080/tcp
  ```
- **预检状态**：已验证 Nginx upstream 正常，Fastify 监听 3008 回环正常。

### 【批次 3】磁盘安全受控清理（释放约 1.4GB）
- **变更目的**：安全回收临时构建残留与无用孤儿缓存，缓解 88% 磁盘高水位。
- **操作对象**：
  1. 删除 `/tmp/dist_upload.tar.gz` (403 MB)
  2. 删除 `/tmp/com.google.Chrome.scoped_dir.*` (约 834 MB)
  3. 清理已轮转且过期的系统 journal 日志（`journalctl --vacuum-time=3d`）
- **影响范围**：仅清理临时目录无用文件，严禁触碰其他项目目录与系统配置。
- **是否停机**：**零停机**。
- **回滚方式**：临时文件无业务依赖，不涉及回滚。
- **预检状态**：已通过 `analyze_audit.py` 与路径排他性审计。

### 【批次 4】下载源数据库坏链与重复项治理
- **变更目的**：清理 Visual Studio Code 等软件绑定的 404 重复历史链接，修复 7-Zip ARM64 链接。
- **操作对象**：PostgreSQL 数据库 `DownloadSource` 表。
- **影响范围**：受影响软件的下载按钮指向更稳定的官方页面。
- **是否停机**：**零停机**。
- **回滚方式**：先执行 `pg_dump` 备份，支持按表恢复。
- **预检状态**：97 条下载源探测结果已本地完整留存。
