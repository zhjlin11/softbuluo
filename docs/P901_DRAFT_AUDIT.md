## 一、可解释性质量审核评分标准 (0–100 分)

为了保障入库与发布软件的客观质量，P9.0.1 制定了**完全透明、可解释的 9 维质量核验量规**。该评分不伪装为用户打分，仅作为后台资源完整度与可信度指标：

| 评估维度 | 分值 | 审核要求与达标准则 |
|---|---:|---|
| **1. 软件名称与原厂开发者** | 10 | 官方正式命名，明确原厂企业或核心开发者/开源组织，无错别字。 |
| **2. 官方网站与主域权威性** | 15 | 拥有已注册官方主域名或顶级开源托管页 (GitHub/GitLab)，且完成 DNS/TLS 有效性检验。 |
| **3. 版本号与发布日期来源** | 15 | 严格源自原厂 Release 声明或更新日志，严禁将数据库更新时间 `updatedAt` 伪充发版日期。 |
| **4. 操作系统与系统架构兼容** | 10 | 准确标明适用 OS (如 Windows 10/11) 及架构适配 (x64 / x86 / ARM64)。 |
| **5. 软件许可证与版权合规** | 10 | 明确具体开源协议 (MIT, GPL-3.0, Apache-2.0, BSD) 或商业/免费许可 (Freeware)。 |
| **6. 有效且可信的下载渠道** | 20 | 至少具备 1 条官方直达或经 Level 4 审核的真实下载来源，严禁挂羊头卖狗肉的捆绑包。 |
| **7. 软件功能描述与核心场景** | 10 | 客观、翔实的软件简介与 3 项以上核心功能，杜绝千篇一律的通用模板生成。 |
| **8. 官方高清图标与界面素材** | 5 | 官方 SVG/PNG 图标或授权界面截图，严禁 AI 凭空臆造虚假 UI。 |
| **9. 类别归属与 SEO 规范元数据** | 5 | 准确挂载至七大主频道，具备标准 Title / Description / Canonical 标签。 |
| **总计** | **100** | **得分 >= 85 且无任何阻断项方可进入发布候选池** |

## 二、六大绝对发布阻断项 (Blocking Criteria)

即便评分达到 85 分以上，只要命中以下**任一阻断红线**，一律由状态机强制拦截发布：
1. **[BLOCK-01] 无合法来源**：下载链接全部 404 或解析失败。
2. **[BLOCK-02] 软件身份存疑**：无法确定官方开发者或官方网站。
3. **[BLOCK-03] 版权侵权与破解**：商业收费软件被标注为“破解版/绿色无毒版”。
4. **[BLOCK-04] 安装包架构错配**：将 ARM64 或 Linux 安装包展示给普通 Windows x64 用户作为默认文件。
5. **[BLOCK-05] 存在反代/SSRF风险**：下载地址指向私有网络、本地回环或云元数据服务。
6. **[BLOCK-06] 属于测试数据**：资源标记有 `isTestData = true` 或含有开发阶段占位信息。

## 四、去重核验说明
