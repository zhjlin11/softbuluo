# 软游部落 P9.0.2 —— 软件质量评分体系与发布阻断准入规范

## 一、规范目标与建设背景

为彻底杜绝传统下载网站“为填充数量而收录劣质软件”、“盗版流氓捆绑混入”、“下载死链失效”等恶疾，软游部落在 P9.0.2 阶段建立了全流程可量化、可审计的**软件质量评分体系（0–100 分制）**与**9 项绝对发布阻断机制（一票否决）**。

任何进入软游部落正式发布池的软件，必须同时满足：
1. **综合质量评分 ≥ 85 分**；
2. **四大核心维度（官方域名、开源免费许可、官方直链、纯净无捆绑）必须满分**；
3. **9 项阻断红线零命中**。

## 二、0–100 软件质量评分体系（10 大维度）

| 维度序号 | 审核评估维度 | 核心项标识 | 满分 | 评分细则与考核标准 |
| :---: | :--- | :---: | :---: | :--- |
| **01** | **真实官方域名核验** | **【核心项】** | **10分** | • 必须为主管开发者/基金会官方所属域名或权威 GitHub/GitLab 官方仓库（10分）<br>• 第三方或次级非官方授权分发站（0分，一票否决） |
| **02** | **权威发布渠道与签名** | 一般项 | **10分** | • 官方 Releases 发布页、具有微软/开发者有效数字签名证书（10分）<br>• 无数字签名但来源确证（5分）<br>• 来源未知（0分） |
| **03** | **明确开源与免费授权** | **【核心项】** | **10分** | • 具有清晰合法的开源许可（GPL、MIT、Apache、BSD、AGPL）或官方明确免费声明（Freeware）（10分）<br>• 破解版、绿色精简版、商业盗版（0分，一票否决） |
| **04** | **语义化版本与发布日期** | 一般项 | **10分** | • 符合 SemVer（如 `1.8.2`、`16.1.0`）或标准版本格式，且有明确官方发布日期（10分）<br>• 版本号模糊（如“最新版”、“v1”）（0分） |
| **05** | **系统架构与平台适配** | 一般项 | **10分** | • 明确标注支持 Windows 10/11，且区分 x64、x86、ARM64 或 UEFI 运行环境（10分）<br>• 未标明架构（5分）<br>• 架构混淆（0分） |
| **06** | **官方直接下载或发布页** | **【核心项】** | **10分** | • 官方可达 HTTPS 直链（如 .zip / .exe / .msix）或官方 Releases 原生页面（10分）<br>• 经过跳转短链或第三方非官方镜像（0分，一票否决） |
| **07** | **中文详细描述与功能清单** | 一般项 | **10分** | • 提供专业、完整、排版优良的中立中文介绍，列明核心功能点与适用人群（10分）<br>• 仅一两句模糊短语（5分）<br>• 无描述（0分） |
| **08** | **官方高清图标与界面展示** | 一般项 | **10分** | • 具备官方高清晰度无水印矢量/PNG 图标，无 Dicebear 随机生成占位图（10分）<br>• 图标分辨率偏低或有轻微水印（5分）<br>• 无图标或占位碎图（0分） |
| **09** | **SEO 规范化元数据** | 一般项 | **10分** | • 具备规范 Title（含品牌词）、Description（50–160字）、H1 标签、Canonical 绝对自指与 JSON-LD 结构化数据（10分）<br>• 缺失某项 SEO 要素（5分） |
| **10** | **零捆绑、零流氓行为** | **【核心项】** | **10分** | • 经 VirusTotal 或人工沙箱核验，100% 无静默安装、无流氓首页劫持、无全家桶推广（10分）<br>• 存在捆绑软件（0分，一票否决） |

### 合格基准判定标准
$$\text{总分} = \sum_{i=1}^{10} S_i$$
$$\text{准入条件} = (\text{总分} \ge 85) \land (S_1 = 10) \land (S_3 = 10) \land (S_6 = 10) \land (S_{10} = 10) \land (\text{阻断项命中数} = 0)$$

## 三、9 项绝对发布阻断机制（一票否决）

在软件审核与增量发布过程中，命中以下任意 1 项即刻触发**发布阻断**，软件保持 `DRAFT` 状态或执行归档，严禁进入发布事务：

1. **阻断项 1：域名无法核实或属于流氓下载站**
   - 官方主页或下载链接指向未经开发者授权的第三方流氓下载站（如含有推广高速下载器的非官方中转页面）。
2. **阻断项 2：缺乏明确合法的免费/开源授权**
   - 包含商业破解补丁、注册机、修改版或存在侵权争议的软件。
3. **阻断项 3：下载链接存在 SSRF 与私网风险**
   - URL 解析到回环地址（`127.0.0.1`）、局域网私有地址（`10.x`、`192.168.x`、`172.16.x`）或云厂商元数据端点（`169.254.169.254`）。
4. **阻断项 4：下载链接包含恶意跳转或推广捆绑器**
   - 重定向跳数超过 3 跳，或跳转至未经白名单审核的外部流氓推广落地页。
5. **阻断项 5：软件核心元数据残缺不全**
   - 缺少开发者名称、版本号缺失、中文功能摘要为空或字数不足 10 字。
6. **阻断项 6：与已发布软件发生重复或命名撞车**
   - 归一化后的 Slug 或软件名称与已有 40 款发布软件重合（如 `7zip`、`vlc` 等）。
7. **阻断项 7：属于测试数据或开发占位资源**
   - 数据库标记为 `isTestData = true`，或 Slug 以 `test-` 开头。
8. **阻断项 8：SEO Canonical 规范标签或路由冲突**
   - Canonical 链接不自指，或与七大主导航现有路由产生路径冲突。
9. **阻断项 9：未通过权限控制或事务原子性验证**
   - 操作账号非 `SUPER_ADMIN` / `ADMIN` / `REVIEWER`，或发布未能纳入原子级 Prisma 事务。
