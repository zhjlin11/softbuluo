## 风险控制与应急回滚方案

1. **Nginx 配置修改风险控制**：
   - 在修改生产 `/etc/nginx/sites-available/softtribe.top.conf` 前，强制执行 `cp softtribe.top.conf softtribe.top.conf.bak.$(date +%Y%m%d%H%M%S)`；
   - 必须通过 `sudo nginx -t` 语法检查后，方可执行 `sudo systemctl reload nginx`；
   - 若出现 502 Bad Gateway，立即恢复备份文件并执行 reload，回滚窗口 < 30 秒。
2. **Fastify 代码热更新风险控制**：
   - 所有 TypeScript 代码在本地必须通过 `npx tsc --noEmit` 严格类型检查；
   - 涉及 Sitemap 与 SSR 逻辑的变更，需先在本地运行单元测试与路由校验，确保输出 XML 与 HTML 格式无语法错误；
   - 生产环境发布需经 PM2 平滑重启（`pm2 reload softtribe-backend`），零停机中断服务。
3. **内容发布合规与审核风控**：
   - 扩充的教程必须严格依据官方真实环境实操编写，禁止使用未经核验的虚假指令或存在安全隐患的破解步骤；
   - 严格遵循七大主导航架构，不擅自将历史废弃频道恢复到主菜单。
